# Flaq SaaS Template (العربية)

قالب SaaS مجاني ومفتوح المصدر لبناء منصات إنشاء الصور والفيديو بالذكاء الاصطناعي عبر واجهة [Flaq.ai](https://flaq.ai). يتضمن أداة موحّدة لإنشاء الصور والفيديو، وسير عمل للفيديو باستخدام المراجع، ولوحة AI Canvas غير محدودة مع إدارة محلية للمشاريع.

## البدء

### المتطلبات

- **Node.js 22**، الإصدار المحدد في `.nvmrc`
- **pnpm 10.5.2**، المثبّت في حقل `packageManager` ضمن `package.json`
- حساب [Flaq.ai](https://flaq.ai/ar/) بمفتاح API فعّال

### التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/flaqai/flaq-saas-template.git
cd flaq-saas-template
# 2. تثبيت pnpm إن لم يكن مثبتًا
npm install -g pnpm@10.5.2
# 3. تثبيت الاعتماديات
pnpm install
# 4. نسخ قالب متغيرات البيئة
cp .env.example .env.local
```

### متغيرات البيئة

عدّل `.env.local` واضبط المتغيرات التالية:

```bash
# عنوان الموقع للبيانات الوصفية وخريطة الموقع وOpen Graph
NEXT_PUBLIC_SITE_URL="http://localhost:3000"
# بريد التواصل المعروض في التذييل
NEXT_PUBLIC_CONTACT_US_EMAIL="contact@flaq.ai"
# اختياري: تخزين Cloudflare R2 الخاص بك، وبيانات الاعتماد على الخادم فقط
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=
```

### رفع الملفات

يستخدم الرفع افتراضيًا API URL وClient Key المضبوطين في **Open API Settings**. لاستخدام Cloudflare R2 الخاص بك، اضبط `R2_ACCOUNT_ID` و`R2_ACCESS_KEY_ID` و`R2_SECRET_ACCESS_KEY` و`R2_BUCKET_NAME` على الخادم، ثم أدخل النطاق العام ضمن **Image Hosting (R2)** في نافذة الإعدادات واحفظ. احتفظ ببيانات اعتماد R2 على الخادم فقط. استخدم **Test R2 Connection** للتحقق من إعداد التخزين.

عند ضبط نطاق عام، يستخدم الرفع تخزين R2 أولًا. امسح النطاق العام واحفظ للعودة إلى رفع Flaq. تظهر أخطاء التخزين الخاص دون التحويل التلقائي إلى Flaq.

عند استخدام Flaq، يطلب التطبيق روابط الرفع من `POST /api/v1/files/presignedUrl`، ثم يرفع كل ملف مباشرة باستخدام `PUT`. يدعم كل طلب 10 ملفات كحد أقصى، وتُرفع المجموعات الأكبر على دفعات متتالية؛ مثلًا، تُقسم 14 ملفًا إلى دفعتين من 10 و4. تُرفع كل دفعة فور الحصول على الروابط، إذ تنتهي صلاحيتها بعد 60 ثانية. تُستخدم الروابط العامة المُعادة في طلبات الإنشاء.

### إعداد مفتاح API الخاص بـ Flaq.ai

1. سجّل حسابًا أو سجّل الدخول إلى [flaq.ai](https://flaq.ai/ar/).
2. انتقل إلى لوحة حسابك.
3. أنشئ Client Key من قسم API Keys.
4. انسخ Client Key.
5. افتح التطبيق واضغط على أيقونة الترس (⚙️) في الرأس لفتح **Open API Settings**.
6. الصق المفتاح واضغط **Test Connection** للتحقق.
7. احفظ الإعدادات.

> **💡 نصيحة:** فعّل **Remember Me** للاحتفاظ بالمفتاح بين الجلسات في تخزين محلي مشفّر. اترك الخيار غير مفعّل على الأجهزة المشتركة أو العامة.

> **🔑 رصيد API:** تحتاج إلى رصيد كافٍ لإنشاء الصور والفيديو. اشحن رصيدك في [flaq.ai](https://flaq.ai/ar/) عند الحاجة.

## إمكانات AIGC

يجمع القالب بين صفحات إنشاء متخصصة وأداة إنشاء مشتركة ولوحة غير محدودة، باستخدام واجهة [Flaq.ai](https://flaq.ai).

| الإمكانية | المسار | الوصف |
| --- | --- | --- |
| النص إلى صورة | `/text-to-image/` | إنشاء صور من أوصاف نصية |
| الصورة إلى صورة | `/image-to-image/` | تحرير الصور بالأوصاف والصور المرجعية |
| النص إلى فيديو | `/text-to-video/` | إنشاء فيديو من أوصاف نصية |
| الصورة إلى فيديو | `/image-to-video/` | إنشاء فيديو من الصور مع التحكم بالإطار النهائي للنماذج المتوافقة |
| الفيديو باستخدام المراجع | `/reference-to-video/` | تجهيز المراجع ثم متابعة الإنشاء في AI Media Creator |
| تجربة الملابس الافتراضية | `/virtual-try-on/` | دمج صورة شخص مع صور ملابس لمعاينة الإطلالة |
| AI Media Creator | `/ai-media-creator/` | إنشاء الصور والفيديو في مساحة واحدة وتصفح سجل الإنشاء |
| AI Canvas | `/ai-canvas/` | إنشاء مسارات عمل مرئية مترابطة وإدارة مشاريع اللوحة |

توجد تعريفات النماذج في `lib/constants/template-models/`، مجمّعة حسب المزوّد ونوع الوسائط. تشمل أمثلة نماذج الصور Nano Banana Pro وNano Banana 2 وGPT Image 2 وChatGPT Images 2.5 وQwen Image 3.0 وSeedream 5.0. وتشمل أمثلة نماذج الفيديو Kling 3.0 وVeo 3.1 وWan 2.7 وSeedance 2.0 وVidu Q3. تعتمد المدخلات والمعلمات المتاحة على النموذج المختار؛ ويستخدم كل نموذج إدخال الإعدادات المقابلة له.

لتجربة الملابس الافتراضية خيارات نماذج خاصة: GPT Image 2 Edit وNano Banana Pro Edit وNano Banana 2 Edit وSeedream 5.0 Edit وSeedream 4.5 Edit.

### AI Media Creator

استخدم `/ai-media-creator/` للتبديل بين إنشاء الصور والفيديو، واختيار النموذج وإضافة المدخلات وضبط المعلمات المدعومة. يدعم الفيديو باستخدام المراجع الصور والفيديو والصوت والمستندات والروابط حيث يسمح النموذج المختار، مع الإشارة إلى المراجع داخل محرر الوصف.

تُتابع حالة الإنشاء تلقائيًا وتظهر النتائج في السجل. يُحفظ سجل الصور والفيديو في التخزين المحلي للمتصفح الحالي.

### AI Canvas

ابدأ من `/ai-canvas/`، وأدر المشاريع المحفوظة في `/ai-canvas/projects/`، وافتح المشروع الفردي في `/ai-canvas/{projectId}/`. يجهّز نموذج البداية مشروعًا وفق إعدادات الإنشاء والمدخلات التي تختارها.

- رتّب عقد الوسائط والإنشاء واربطها على لوحة غير محدودة
- أنشئ الصور والفيديو باستخدام اتصال API المضبوط
- احفظ المشاريع محليًا في IndexedDB وأعد فتحها من لوحة المشاريع
- أعد تسمية المشاريع أو احذفها أو استوردها أو صدّرها، بما في ذلك أرشيفات ZIP التي تتضمن وسائط المشروع

ترتبط المشاريع بالمتصفح وأصل الموقع الحاليين؛ ولا توجد مزامنة للمشاريع عبر الحساب. صدّر نسخة قابلة للنقل قبل مسح بيانات المتصفح أو الانتقال إلى جهاز أو نطاق آخر.

## برنامج Flaq.ai للتسويق بالعمولة

تتضمن صفحات الهبوط والإنشاء العامة ترويجًا محليًا لـ [برنامج Flaq.ai للتسويق بالعمولة](https://flaq.ai/ar/affiliate-program?utm_source=flaq-saas-template). يفتح زر الدعوة إلى الإجراء صفحة Flaq.ai باللغة المناسبة، ويتضمن `utm_source=flaq-saas-template` لتحديد مصدر الزيارة.

وفق الشروط الحالية، يمكن الحصول على 20% من أول طلب مدفوع صالح للمستخدم المُحال، و10% من الطلبات المدفوعة الصالحة اللاحقة خلال 60 يومًا من تسجيله. تخضع الأهلية والدفع للشروط المنشورة في صفحة البرنامج.

## التدويل

يدعم القالب **15 لغة** جاهزة: الإنجليزية افتراضيًا، واليابانية والإندونيسية والإيطالية والبرتغالية البرازيلية والإسبانية والألمانية والروسية والفرنسية والصينية المبسطة والصينية التقليدية والكورية والتايلاندية والفيتنامية والعربية.

- توجد الترجمات في `messages/`، بملف JSON لكل لغة
- تُكتشف اللغة من ترويسة `Accept-Language` في المتصفح
- يمكن تغيير اللغة يدويًا من التذييل أو نافذة اختيار اللغة
- تستخدم الإنجليزية `/` وبقية اللغات `/{locale}/`، مثل `/ja/` أو `/zh/`
- تستخدم الصفحات العربية اتجاهًا من اليمين إلى اليسار تلقائيًا

لإضافة لغة:

1. أضف رمز اللغة إلى `i18n/languages.ts`.
2. أنشئ ملف ترجمة في `messages/`.
3. أضف نصوص الصفحات وترجمات `Metadata` وفق بنية المفاتيح الحالية.

## تحسين محركات البحث واكتشاف المحتوى عبر زواحف الذكاء الاصطناعي

تستخدم الصفحات العامة عناوين وأوصافًا محلية، وعنوان canonical مطلقًا، وبدائل `hreflang` لـ 15 لغة، وبيانات Open Graph وبطاقة Twitter وتعليمات index/follow. يتضمن `/sitemap.xml` الصفحة الرئيسية وصفحات الميزات والسياسات بكل اللغات مع بدائلها المطابقة. لا تُدرج روابط مشاريع اللوحة المحلية الفردية.

- يسمح `/robots.txt` لمحركات البحث ومساعدي الذكاء الاصطناعي بالوصول إلى المحتوى العام، ويحجب مسارات API وردود الاستدعاء
- يوفر `/llms.txt` خريطة موجزة ومنظّمة للمنتج والصفحات واللغات والتوثيق والسياسات
- يوفر `/llms-full.txt` سياقًا موسّعًا للمشروع وإمكاناته وإعداده وبنيته وحدود الاستخدام
- يعرّف JSON-LD الموقع والمستودع مفتوح المصدر المرخّص وفق MIT، دون تقييمات لا يمكن التحقق منها

اضبط `NEXT_PUBLIC_SITE_URL` على أصل موقع الإنتاج قبل النشر لضمان استخدام النطاق الصحيح في روابط canonical وخريطة الموقع وموارد LLM.

## النشر

أسهل طريقة لنشر القالب هي عبر [Vercel](https://vercel.com):

[![النشر عبر Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/flaqai/flaq-saas-template)

1. ادفع المستودع إلى GitHub.
2. استورد المشروع في Vercel.
3. اضبط `NEXT_PUBLIC_SITE_URL` على أصل موقع الإنتاج وبريد التواصل في إعدادات مشروع Vercel.
4. عند استخدام R2 خاص، أضف متغيرات الخادم الأربعة `R2_*` واضبط النطاق العام في التطبيق.
5. انشر المشروع.

يتضمن التطبيق مسارات خادم لرفع الملفات ووكالة الصور، لذا يتطلب بيئة تشغيل خادم Next.js. للاستضافة الذاتية على Node.js، شغّل `pnpm build` ثم `pnpm start`. شغّل `pnpm ts-check` بصورة منفصلة قبل النشر، لأن إعداد Next.js الحالي يتجاوز أخطاء TypeScript أثناء البناء.
