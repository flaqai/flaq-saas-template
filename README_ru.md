# Flaq SaaS Template (Русский)

Бесплатный SaaS-шаблон с открытым исходным кодом для создания платформ генерации изображений и видео с помощью API [Flaq.ai](https://flaq.ai). Включает единый инструмент создания изображений и видео, работу с референсами и бесконечный AI Canvas с локальным управлением проектами.

## Возможности

- 🎨 **Текст в изображение** — генерация изображений по текстовому описанию с помощью современных моделей ИИ
- 🖼️ **Изображение в изображение** — творческие вариации исходных изображений с сохранением стиля
- 🎬 **Текст в видео** — создание качественных видео по текстовому описанию
- 📹 **Изображение в видео** — превращение статичных изображений в видео
- 🧩 **AI Media Creator** — общая форма для изображений и видео с настройками выбранной модели
- 🎞️ **Видео по референсам** — изображения, видео, аудио, документы или ссылки в зависимости от модели
- 🗂️ **AI Canvas** — связанные узлы медиа и генерации на бесконечном холсте, локальные проекты, импорт и экспорт ZIP
- 👗 **Виртуальная примерка** — примерка одежды с помощью ИИ
- 🌐 **Интернационализация** — 15 локалей, согласованных с Flaq.ai, с локализованными маршрутами и альтернативными SEO-ссылками
- 🚀 **Без регистрации в приложении** — изучайте, изменяйте и размещайте шаблон самостоятельно
- 🤝 **Партнёрская программа** — адаптивный блок Flaq.ai с локализованным текстом и ссылками
- 🔒 **Защита API-ключа** — зашифрованное хранение учётных данных Flaq.ai на стороне клиента
- ☁️ **Загрузка файлов** — через API-ключ Flaq или собственное хранилище Cloudflare R2
- 📱 **Адаптивный интерфейс** — Tailwind CSS и Radix UI
- 🌓 **Тёмная тема** — готовый интерфейс в тёмных тонах
- ⚡ **Производительность** — Next.js 16 с поддержкой Turbopack
- 🔍 **SEO** — динамические метаданные, Open Graph, sitemap и структурированные данные
- 🤖 **Доступ для ИИ** — `llms.txt`, расширенный `llms-full.txt` и доступ к публичным страницам для роботов

## Начало работы

### Требования

- **Node.js 22**, указанный в `.nvmrc`
- **pnpm 10.5.2**, закреплённый в поле `packageManager` файла `package.json`
- Аккаунт [Flaq.ai](https://flaq.ai/ru/) с действующим API-ключом

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/flaqai/flaq-saas-template.git
cd flaq-saas-template
# 2. Установите pnpm, если он ещё не установлен
npm install -g pnpm@10.5.2
# 3. Установите зависимости
pnpm install
# 4. Скопируйте шаблон переменных окружения
cp .env.example .env.local
```

### Переменные окружения

Настройте следующие значения в `.env.local`:

```bash
# URL сайта для метаданных, sitemap и Open Graph
NEXT_PUBLIC_SITE_URL="http://localhost:3000"
# Контактный email в нижней части страницы
NEXT_PUBLIC_CONTACT_US_EMAIL="contact@flaq.ai"
# Необязательно: собственное Cloudflare R2, учётные данные только на сервере
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=
```

### Загрузка файлов

По умолчанию используются API URL и Client Key из **Open API Settings**. Для собственного Cloudflare R2 задайте `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` и `R2_BUCKET_NAME` на сервере, затем укажите публичный домен в разделе **Image Hosting (R2)** диалога настроек и сохраните. Храните учётные данные R2 только на сервере. Проверьте конфигурацию кнопкой **Test R2 Connection**.

При заданном публичном домене загрузка в первую очередь использует R2. Очистите домен и сохраните настройки, чтобы вернуться к загрузке Flaq. При ошибках собственного хранилища приложение сообщает об ошибке без автоматического переключения на Flaq.

Для загрузки Flaq приложение запрашивает URL через `POST /api/v1/files/presignedUrl`, затем отправляет каждый файл напрямую методом `PUT`. Один запрос поддерживает до 10 файлов; большие наборы загружаются последовательно, например 14 файлов — группами по 10 и 4. Загрузка каждой группы начинается сразу после получения URL, срок действия которых составляет 60 секунд. Полученные публичные URL используются в запросах генерации.

### Настройка API-ключа Flaq.ai

1. Зарегистрируйтесь или войдите на [flaq.ai](https://flaq.ai/ru/).
2. Откройте панель своего аккаунта.
3. Создайте Client Key в разделе API Keys.
4. Скопируйте Client Key.
5. Нажмите значок шестерёнки (⚙️) в шапке приложения, чтобы открыть **Open API Settings**.
6. Вставьте ключ и нажмите **Test Connection**.
7. Сохраните настройки.

> **💡 Совет:** опция **Remember Me** сохраняет ключ между сеансами в зашифрованном локальном хранилище. На общих и публичных устройствах оставляйте её выключенной.

> **🔑 Баланс API:** для генерации изображений и видео нужен достаточный баланс. При необходимости пополните его на [flaq.ai](https://flaq.ai/ru/).

## Возможности AIGC

Шаблон объединяет отдельные страницы генерации, общий инструмент создания контента и бесконечный холст на базе API [Flaq.ai](https://flaq.ai).

| Возможность | Маршрут | Описание |
| --- | --- | --- |
| Текст в изображение | `/text-to-image/` | Генерация изображений по тексту |
| Изображение в изображение | `/image-to-image/` | Редактирование по тексту и изображениям-референсам |
| Текст в видео | `/text-to-video/` | Генерация видео по тексту |
| Изображение в видео | `/image-to-video/` | Генерация видео из изображений с управлением конечным кадром у совместимых моделей |
| Видео по референсам | `/reference-to-video/` | Подготовка референсов и продолжение генерации в AI Media Creator |
| Виртуальная примерка | `/virtual-try-on/` | Предпросмотр образа по фотографии человека и изображениям одежды |
| AI Media Creator | `/ai-media-creator/` | Генерация изображений и видео в одном пространстве с историей результатов |
| AI Canvas | `/ai-canvas/` | Связанные визуальные процессы и управление проектами холста |

Определения моделей находятся в `lib/constants/template-models/` и сгруппированы по поставщику и типу медиа. Среди моделей изображений — Nano Banana Pro, Nano Banana 2, GPT Image 2, ChatGPT Images 2.5, Qwen Image 3.0 и Seedream 5.0. Среди видеомоделей — Kling 3.0, Veo 3.1, Wan 2.7, Seedance 2.0 и Vidu Q3. Доступные входные данные и параметры зависят от выбранной модели; каждая форма использует её конфигурацию.

У виртуальной примерки отдельный набор моделей: GPT Image 2 Edit, Nano Banana Pro Edit, Nano Banana 2 Edit, Seedream 5.0 Edit и Seedream 4.5 Edit.

### AI Media Creator

На `/ai-media-creator/` переключайтесь между изображениями и видео, выбирайте модель, добавляйте входные данные и настраивайте поддерживаемые параметры. Для видео по референсам доступны изображения, видео, аудио, документы и ссылки, если модель их поддерживает, с упоминаниями референсов в редакторе запроса.

Статус генерации проверяется автоматически, результаты появляются в истории. История изображений и видео хранится локально в текущем браузере.

### AI Canvas

Начните на `/ai-canvas/`, управляйте сохранёнными проектами на `/ai-canvas/projects/` и открывайте отдельный проект по адресу `/ai-canvas/{projectId}/`. Начальная форма подготавливает проект из выбранных настроек генерации и входных данных.

- Размещайте и соединяйте узлы медиа и генерации на бесконечном холсте
- Генерируйте изображения и видео через настроенное подключение к API
- Сохраняйте проекты локально в IndexedDB и открывайте их из панели проектов
- Переименовывайте, удаляйте, импортируйте и экспортируйте проекты, включая ZIP-архивы с медиафайлами

Проекты привязаны к текущему браузеру и origin сайта; синхронизации через аккаунт нет. Экспортируйте переносимую копию перед очисткой данных браузера или переходом на другое устройство либо домен.

## Партнёрская программа Flaq.ai

На публичных посадочных страницах и страницах генерации размещён локализованный блок [партнёрской программы Flaq.ai](https://flaq.ai/ru/affiliate-program?utm_source=flaq-saas-template). Ссылка открывает соответствующую языковую версию Flaq.ai и содержит `utm_source=flaq-saas-template` для определения источника перехода.

По текущим условиям можно получать 20% с первого действительного оплаченного заказа привлечённого пользователя и 10% с последующих действительных оплаченных заказов в течение 60 дней после регистрации. Условия участия и выплат определяются правилами на странице программы.

## Интернационализация

Поддерживаются **15 локалей**: английский (по умолчанию), японский, индонезийский, итальянский, бразильский португальский, испанский, немецкий, русский, французский, упрощённый китайский, традиционный китайский, корейский, тайский, вьетнамский и арабский.

- Переводы находятся в `messages/`, по одному JSON-файлу на локаль
- Язык определяется по заголовку браузера `Accept-Language`
- Переключение доступно в нижней части страницы или диалоге выбора языка
- Английская версия использует `/`, остальные — `/{locale}/`, например `/ja/` или `/zh/`
- Арабские страницы автоматически отображаются справа налево

Чтобы добавить язык:

1. Добавьте локаль в `i18n/languages.ts`.
2. Создайте файл перевода в `messages/`.
3. Добавьте тексты страниц и переводы `Metadata` с существующей структурой ключей.

## SEO и доступ для ИИ

Публичные страницы используют локализованные заголовки и описания, абсолютный canonical URL, альтернативы `hreflang` для 15 языков, Open Graph, Twitter card и директивы index/follow. `/sitemap.xml` включает главную страницу, страницы функций и политики на всех языках с соответствующими альтернативами. Адреса отдельных локальных проектов холста не включаются.

- `/robots.txt` разрешает поисковым системам и ИИ-ассистентам обход публичного контента, блокируя маршруты API и обратных вызовов
- `/llms.txt` содержит краткую структурированную карту продукта, страниц, языков, документации и политик
- `/llms-full.txt` расширяет контекст проекта, возможности, инструкции настройки, архитектуру и границы использования
- JSON-LD описывает сайт и открытый репозиторий с лицензией MIT без непроверяемых рейтингов

Перед развёртыванием задайте производственный origin в `NEXT_PUBLIC_SITE_URL`, чтобы canonical, sitemap и ресурсы LLM использовали правильный домен.

## Развёртывание

Проще всего развернуть шаблон через [Vercel](https://vercel.com):

[![Развернуть в Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/flaqai/flaq-saas-template)

1. Отправьте репозиторий в GitHub.
2. Импортируйте проект в Vercel.
3. Задайте производственный origin в `NEXT_PUBLIC_SITE_URL` и контактный email в настройках проекта Vercel.
4. Для собственного R2 добавьте четыре серверные переменные `R2_*` и настройте публичный домен в приложении.
5. Выполните развёртывание.

Загрузка файлов и проксирование изображений используют серверные маршруты, поэтому требуется серверная среда Next.js. При самостоятельном размещении на Node.js выполните `pnpm build`, затем `pnpm start`. Перед развёртыванием отдельно выполните `pnpm ts-check`: текущая конфигурация Next.js пропускает ошибки TypeScript при сборке.
