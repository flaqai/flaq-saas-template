# Flaq SaaS Template (ภาษาไทย)

เทมเพลต SaaS ฟรีและโอเพนซอร์สสำหรับสร้างแพลตฟอร์มสร้างภาพและวิดีโอด้วย AI ผ่าน API ของ [Flaq.ai](https://flaq.ai) มาพร้อมเครื่องมือสร้างภาพและวิดีโอในที่เดียว การสร้างวิดีโอจากสื่ออ้างอิง และแคนวาส AI แบบไม่จำกัดพร้อมการจัดการโครงการในเครื่อง

## คุณสมบัติ

- 🎨 **ข้อความเป็นภาพ** — สร้างภาพสวยงามจากพรอมป์ต์ด้วยโมเดล AI ที่ทันสมัย
- 🖼️ **ภาพเป็นภาพ** — แปลงภาพเดิมเป็นรูปแบบสร้างสรรค์โดยคงสไตล์ที่สอดคล้องกัน
- 🎬 **ข้อความเป็นวิดีโอ** — สร้างวิดีโอคุณภาพสูงจากคำอธิบายสั้น ๆ
- 📹 **ภาพเป็นวิดีโอ** — เปลี่ยนภาพนิ่งให้เป็นวิดีโอที่เคลื่อนไหว
- 🧩 **AI Media Creator** — สร้างภาพและวิดีโอผ่านแบบฟอร์มเดียว พร้อมตัวควบคุมเฉพาะโมเดล
- 🎞️ **สื่ออ้างอิงเป็นวิดีโอ** — ใช้ภาพ วิดีโอ เสียง เอกสาร หรือลิงก์อ้างอิงตามที่โมเดลรองรับ
- 🗂️ **AI Canvas** — เชื่อมต่อโหนดสื่อและโหนดสร้างผลงานบนแคนวาสไม่จำกัด บันทึกโครงการในเครื่อง และนำเข้าหรือส่งออก ZIP
- 👗 **ลองเสื้อผ้าเสมือนจริง** — ประสบการณ์ลองสวมเสื้อผ้าด้วย AI
- 🌐 **หลายภาษา** — รองรับ 15 ภาษาตรงกับ Flaq.ai พร้อมเส้นทางตามภาษาและลิงก์ภาษาทางเลือกสำหรับ SEO
- 🚀 **ไม่ต้องสมัคร** — สำรวจ แก้ไข และโฮสต์เทมเพลตเองได้โดยไม่ต้องสร้างบัญชีแอป
- 🤝 **โปรโมตพันธมิตร** — ส่วนแนะนำโปรแกรมพันธมิตร Flaq.ai ที่รองรับทุกหน้าจอ พร้อมข้อความและลิงก์ตามภาษา
- 🔒 **จัดการ API Key อย่างปลอดภัย** — เข้ารหัสข้อมูลรับรอง Flaq.ai ในพื้นที่จัดเก็บฝั่งไคลเอนต์
- ☁️ **อัปโหลดไฟล์** — อัปโหลดสื่อด้วย Flaq API Key หรือ Cloudflare R2 ของคุณเอง
- 📱 **รองรับทุกหน้าจอ** — UI แบบตอบสนองสร้างด้วย Tailwind CSS และ Radix UI
- 🌓 **โหมดมืด** — ธีมมืดที่สวยงามพร้อมใช้งาน
- ⚡ **ประสิทธิภาพรวดเร็ว** — ใช้ Next.js 16 พร้อมรองรับ Turbopack
- 🔍 **ปรับแต่ง SEO** — เมทาดาทาแบบไดนามิก Open Graph แผนผังเว็บไซต์ และข้อมูลแบบมีโครงสร้าง
- 🤖 **พร้อมสำหรับ AI Crawler** — มี `llms.txt` แบบสรุป `llms-full.txt` แบบละเอียด และเปิดให้เข้าถึงเนื้อหาสาธารณะ

## เริ่มต้นใช้งาน

### สิ่งที่ต้องมี

- **Node.js 22** (เวอร์ชันที่ระบุใน `.nvmrc`)
- **pnpm 10.5.2** (กำหนดไว้ในฟิลด์ `packageManager` ของ `package.json`)
- บัญชี [Flaq.ai](https://flaq.ai/) พร้อม API Key ที่ใช้งานได้

### การติดตั้ง

```bash
# 1. โคลนที่เก็บโค้ด
git clone https://github.com/flaqai/flaq-saas-template.git
cd flaq-saas-template

# 2. ติดตั้ง pnpm หากยังไม่มี
npm install -g pnpm@10.5.2

# 3. ติดตั้งแพ็กเกจที่จำเป็น
pnpm install

# 4. คัดลอกเทมเพลตตัวแปรสภาพแวดล้อม
cp .env.example .env.local
```

### ตัวแปรสภาพแวดล้อม

แก้ไข `.env.local` และตั้งค่าตัวแปรต่อไปนี้:

```bash
# URL เว็บไซต์ (สำหรับเมทาดาทา แผนผังเว็บไซต์ และ Open Graph)
NEXT_PUBLIC_SITE_URL="http://localhost:3000"

# อีเมลติดต่อที่แสดงในส่วนท้าย
NEXT_PUBLIC_CONTACT_US_EMAIL="contact@flaq.ai"

# ไม่บังคับ: Cloudflare R2 ของคุณเอง (ข้อมูลรับรองเก็บเฉพาะฝั่งเซิร์ฟเวอร์)
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=
```

### การอัปโหลดไฟล์

ตามค่าเริ่มต้น การอัปโหลดใช้ API URL และ Client Key ที่ตั้งค่าใน **Open API Settings** หากต้องการใช้ Cloudflare R2 ของคุณเอง ให้ตั้งค่า `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` และ `R2_BUCKET_NAME` บนเซิร์ฟเวอร์ จากนั้นใส่โดเมนสาธารณะใน **Image Hosting (R2)** ของหน้าต่างตั้งค่าและบันทึก เก็บข้อมูลรับรอง R2 ไว้เฉพาะบนเซิร์ฟเวอร์ และใช้ **Test R2 Connection** เพื่อตรวจสอบการตั้งค่า

เมื่อตั้งค่าโดเมนสาธารณะแล้ว ระบบจะใช้ R2 ของคุณก่อน หากล้างโดเมนและบันทึกจะกลับไปใช้การอัปโหลดของ Flaq เมื่อพื้นที่จัดเก็บของคุณเกิดข้อผิดพลาด ระบบจะแสดงข้อผิดพลาดโดยไม่สลับไปใช้ Flaq

สำหรับ Flaq แอปขอ URL อัปโหลดจาก `POST /api/v1/files/presignedUrl` แล้วอัปโหลดแต่ละไฟล์โดยตรงด้วย `PUT` แต่ละคำขอรองรับสูงสุด 10 ไฟล์ หากมากกว่านั้นจะแบ่งอัปโหลดตามลำดับ เช่น 14 ไฟล์แบ่งเป็น 10 และ 4 ไฟล์ URL มีอายุ 60 วินาที จึงเริ่มอัปโหลดแต่ละชุดทันทีที่ได้รับ URL และใช้ URL สาธารณะที่ส่งกลับมาในคำขอสร้างผลงาน

### การตั้งค่า API Key ของ Flaq.ai

1. **สมัครหรือเข้าสู่ระบบ** ที่ [flaq.ai](https://flaq.ai)
2. **เปิด**แดชบอร์ดบัญชี
3. **สร้าง Client Key** ในส่วน API Keys
4. **คัดลอก** Client Key
5. **เปิด**แอปและกด**ไอคอนเฟือง** (⚙️) ในส่วนหัวเพื่อเปิด **Open API Settings**
6. **วาง** Client Key และกด **Test Connection** เพื่อตรวจสอบ
7. **บันทึก**การตั้งค่า

> **💡 เคล็ดลับ**: เปิด “Remember Me” เพื่อเก็บ API Key ไว้ใช้งานครั้งต่อไป โดยเข้ารหัสในพื้นที่จัดเก็บภายในเบราว์เซอร์ หากใช้อุปกรณ์ร่วมกันหรืออุปกรณ์สาธารณะ ควรปิดตัวเลือกนี้เพื่อความปลอดภัย

> **🔑 เครดิต API**: ต้องมีเครดิต API เพียงพอเพื่อสร้างภาพและวิดีโอ เติมเครดิตได้ที่ [flaq.ai](https://flaq.ai) เมื่อจำเป็น

## ความสามารถด้าน AIGC

เทมเพลตรวมหน้าสร้างผลงานเฉพาะทาง เครื่องมือสร้างร่วม และแคนวาสไม่จำกัด โดยใช้ API ของ [Flaq.ai](https://flaq.ai)

| ความสามารถ | เส้นทาง | คำอธิบาย |
| ----------- | ------- | -------- |
| **ข้อความเป็นภาพ** | `/text-to-image/` | สร้างภาพจากพรอมป์ต์ข้อความ |
| **ภาพเป็นภาพ** | `/image-to-image/` | แก้ไขภาพด้วยพรอมป์ต์และภาพอ้างอิง |
| **ข้อความเป็นวิดีโอ** | `/text-to-video/` | สร้างวิดีโอจากพรอมป์ต์ข้อความ |
| **ภาพเป็นวิดีโอ** | `/image-to-video/` | สร้างวิดีโอจากภาพ พร้อมกำหนดเฟรมสุดท้ายในโมเดลที่รองรับ |
| **สื่ออ้างอิงเป็นวิดีโอ** | `/reference-to-video/` | เตรียมข้อมูลอ้างอิงและสร้างต่อใน AI Media Creator |
| **ลองเสื้อผ้าเสมือนจริง** | `/virtual-try-on/` | รวมภาพบุคคลกับภาพเสื้อผ้าเพื่อดูตัวอย่างการแต่งกาย |
| **AI Media Creator** | `/ai-media-creator/` | สร้างภาพและวิดีโอในพื้นที่เดียว พร้อมดูประวัติการสร้าง |
| **AI Canvas** | `/ai-canvas/` | สร้างเวิร์กโฟลว์ภาพที่เชื่อมต่อกันและจัดการโครงการแคนวาส |

นิยามโมเดลอยู่ใน `lib/constants/template-models/` แบ่งตามผู้ให้บริการและประเภทสื่อ ตัวอย่างโมเดลภาพ ได้แก่ Nano Banana Pro, Nano Banana 2, GPT Image 2, ChatGPT Images 2.5, Qwen Image 3.0 และ Seedream 5.0 ตัวอย่างโมเดลวิดีโอ ได้แก่ Kling 3.0, Veo 3.1, Wan 2.7, Seedance 2.0 และ Vidu Q3 ข้อมูลนำเข้าและพารามิเตอร์ที่ใช้ได้ขึ้นอยู่กับโมเดลที่เลือก โดยแต่ละแบบฟอร์มใช้การตั้งค่าของโมเดลนั้น

การลองเสื้อผ้าเสมือนจริงมีตัวเลือกโมเดลแยกต่างหาก ได้แก่ GPT Image 2 Edit, Nano Banana Pro Edit, Nano Banana 2 Edit, Seedream 5.0 Edit และ Seedream 4.5 Edit

### AI Media Creator

ใช้ `/ai-media-creator/` เพื่อสลับการสร้างภาพและวิดีโอ เลือกโมเดล เพิ่มข้อมูลนำเข้า และตั้งค่าพารามิเตอร์ที่รองรับ การสร้างวิดีโอจากสื่ออ้างอิงรองรับภาพ วิดีโอ เสียง เอกสาร และลิงก์ตามความสามารถของโมเดล พร้อมระบุสื่ออ้างอิงในตัวแก้ไขพรอมป์ต์

ระบบตรวจสอบสถานะการสร้างเป็นระยะโดยอัตโนมัติ และแสดงผลลัพธ์ในประวัติของเครื่องมือ ประวัติภาพและวิดีโอเก็บอยู่ในพื้นที่จัดเก็บภายในเบราว์เซอร์ปัจจุบัน

### AI Canvas

เริ่มที่ `/ai-canvas/` จัดการโครงการที่บันทึกไว้ที่ `/ai-canvas/projects/` และเปิดแต่ละโครงการที่ `/ai-canvas/{projectId}/` แบบฟอร์มเริ่มต้นเตรียมโครงการจากการตั้งค่าการสร้างและข้อมูลนำเข้าที่เลือก

- จัดวางและเชื่อมต่อโหนดสื่อและโหนดสร้างผลงานบนแคนวาสไม่จำกัด
- สร้างภาพและวิดีโอผ่านการเชื่อมต่อ API ที่ตั้งค่าไว้
- บันทึกโครงการใน IndexedDB ของเครื่องและเปิดอีกครั้งจากแดชบอร์ดโครงการ
- เปลี่ยนชื่อ ลบ นำเข้า และส่งออกโครงการ รวมถึง ZIP ที่มีสื่อของโครงการ

โครงการเป็นของเบราว์เซอร์และออริจินเว็บไซต์ปัจจุบัน ไม่มีการซิงค์โครงการผ่านบัญชี ควรส่งออกโครงการเพื่อเก็บสำเนาที่ย้ายได้ก่อนล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนอุปกรณ์หรือโดเมน

## โปรแกรมพันธมิตร Flaq.ai

หน้าแนะนำและหน้าสร้างผลงานสาธารณะมีส่วนประชาสัมพันธ์[โปรแกรมพันธมิตร Flaq.ai](https://flaq.ai/th/affiliate-program?utm_source=flaq-saas-template) ตามภาษา ปุ่มจะเปิดหน้า Flaq.ai ในภาษาที่ตรงกันและมี `utm_source=flaq-saas-template` สำหรับระบุแหล่งที่มา

คุณจะได้รับค่าคอมมิชชัน 20% จากคำสั่งซื้อแบบชำระเงินที่ถูกต้องครั้งแรกของผู้ใช้ที่แนะนำ และ 10% จากคำสั่งซื้อที่ถูกต้องครั้งถัดไปภายใน 60 วันหลังลงทะเบียน คุณสมบัติและการจ่ายเงินเป็นไปตามข้อกำหนดล่าสุดในหน้าโปรแกรม

## การรองรับหลายภาษา

รองรับ **15 ภาษา** ตั้งแต่เริ่มต้น ได้แก่ อังกฤษ (ค่าเริ่มต้น) ญี่ปุ่น อินโดนีเซีย อิตาลี โปรตุเกสแบบบราซิล สเปน เยอรมัน รัสเซีย ฝรั่งเศส จีนตัวย่อ จีนตัวเต็ม เกาหลี ไทย เวียดนาม และอาหรับ

- ไฟล์แปลอยู่ใน `messages/` โดยแต่ละภาษามีไฟล์ JSON หนึ่งไฟล์
- ตรวจจับภาษาจากเฮดเดอร์ `Accept-Language` ของเบราว์เซอร์โดยอัตโนมัติ
- ผู้ใช้สลับภาษาได้จากส่วนท้ายหรือหน้าต่างเลือกภาษา
- ภาษาอังกฤษใช้ `/` ภาษาอื่นใช้ `/{locale}/` เช่น `/ja/` หรือ `/zh/`
- หน้าภาษาอาหรับแสดงเอกสารจากขวาไปซ้ายโดยอัตโนมัติ

การเพิ่มภาษา:

1. เพิ่มภาษาใน `i18n/languages.ts`
2. สร้างไฟล์แปลใน `messages/`
3. เพิ่มคำแปลเนื้อหาหน้าและ `Metadata` ตามโครงสร้างคีย์เดิม

## SEO และการค้นพบโดย AI

หน้าแนะนำและหน้าสร้างผลงานสาธารณะใช้ชื่อและคำอธิบายตามภาษา canonical URL แบบเต็ม ลิงก์ `hreflang` 15 ภาษา Open Graph การ์ด Twitter และคำสั่ง index/follow ไฟล์ `/sitemap.xml` ที่สร้างขึ้นรวมหน้าแรก เส้นทางฟีเจอร์ และหน้านโยบายทุกภาษา พร้อมลิงก์ภาษาทางเลือกที่ตรงกัน โดยไม่รวม URL ของโครงการแคนวาสในเครื่องแต่ละรายการ

- `/robots.txt` อนุญาตให้เสิร์ชเอนจินและผู้ช่วย AI อ่านเนื้อหาสาธารณะ แต่ปิดกั้นเส้นทาง API และ callback
- `/llms.txt` ให้แผนที่แบบย่อที่มีโครงสร้างสำหรับผลิตภัณฑ์ หน้า ภาษา เอกสาร และนโยบาย
- `/llms-full.txt` ให้รายละเอียดบริบทโครงการ ความสามารถ ขั้นตอนตั้งค่า สถาปัตยกรรม และขอบเขตการใช้งาน
- JSON-LD ระบุเว็บไซต์และที่เก็บโค้ดโอเพนซอร์สภายใต้ MIT โดยไม่ใช้คะแนนที่ตรวจสอบไม่ได้

ตั้งค่า `NEXT_PUBLIC_SITE_URL` เป็นออริจินเว็บไซต์ที่ใช้งานจริงก่อนนำขึ้นระบบ เพื่อให้ canonical แผนผังเว็บไซต์ และ URL ทรัพยากร LLM ใช้โดเมนที่ถูกต้อง

## การนำขึ้นใช้งาน

วิธีที่ง่ายที่สุดคือใช้ [Vercel](https://vercel.com):

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/flaqai/flaq-saas-template)

1. ส่งที่เก็บโค้ดขึ้น GitHub
2. นำเข้าโครงการใน Vercel
3. ตั้งค่า `NEXT_PUBLIC_SITE_URL` เป็นออริจินเว็บไซต์ที่ใช้งานจริงและกำหนดอีเมลติดต่อในหน้าตั้งค่าโครงการ Vercel
4. หากใช้ R2 ของคุณเอง ให้เพิ่มตัวแปร `R2_*` ฝั่งเซิร์ฟเวอร์ทั้งสี่รายการ และตั้งค่าโดเมนสาธารณะในแอป
5. นำขึ้นใช้งาน

แอปมีเส้นทางเซิร์ฟเวอร์สำหรับอัปโหลดและพร็อกซีภาพ จึงต้องใช้สภาพแวดล้อมเซิร์ฟเวอร์ Next.js หากโฮสต์ด้วย Node.js เอง ให้เรียก `pnpm build` แล้วตามด้วย `pnpm start` ก่อนนำขึ้นใช้งานให้เรียก `pnpm ts-check` แยกต่างหาก เนื่องจากการตั้งค่า Next.js ปัจจุบันข้ามข้อผิดพลาด TypeScript ระหว่างการบิลด์
